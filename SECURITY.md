## Reporting a Vulnerability

The Nexora AI engineering team takes security and privacy seriously. If you discover a security vulnerability within this repository, please follow responsible disclosure guidelines:

### 1. Do NOT Open a Public Issue
Please do **not** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

### 2. How to Report
Please disclose the vulnerability via one of the following methods:
- **Private Vulnerability Reporting**: Use GitHub's built-in [Private Security Advisories](https://github.com/Mahdi-Soleimani/NexoraAILog/security/advisories/new).
- **Direct Email**: Send details directly to `mahdisoleimani2003@gmail.com` with the subject tag `[SECURITY VULNERABILITY] NexoraAILog`.

### 3. What to Include in Your Report
To help us triage and resolve the issue quickly, please include:
- A descriptive summary of the vulnerability.
- Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
- Impact assessment (e.g., potential for data exposure, client-side injection).
- Any proposed mitigations or remediation steps if available.

### 4. Response Timeline
- **Acknowledgement**: Within 48 hours of initial receipt.
- **Triage & Assessment**: Within 5 business days.
- **Fix & Public Advisory**: Coordinated release following patch validation.

Thank you for helping keep the open-source ecosystem secure!
